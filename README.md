# 🧾 Invoicely — Free Freelance Invoice Generator

A lightweight, zero-dependency, high-converting client-side **Freelance Invoice Generator** designed for freelancers, contractors, and agency owners.

---

## ✨ Features

- **Instant PDF Export & Print**: 1-click pixel-perfect PDF export formatted for standard A4 pages with zero clutter.
- **Real-Time Dynamic Calculations**: Automatic item total, subtotal, percentage or flat discounts, configurable tax rates (VAT/GST/Sales tax), shipping/extra fees, and balance due tracking.
- **Custom Branding & Theming**:
  - Drag-and-drop / upload custom company logo (auto-converted to Base64).
  - 6 preset accent colors + custom Hex color picker.
  - Multi-currency support (USD, PKR, EUR, GBP, INR, CAD, AUD, JPY, AED, SAR, and custom symbols).
  - Status badges (Draft, Pending, Paid, Overdue).
- **Auto-Save & Local History**: Automatically saves work to `localStorage` in the user's browser (100% private, no backend server needed).
- **Preset Quick-Add**: Pre-configured common freelance services (Web Dev, UI/UX, SEO retainer, Cloud/DevOps).
- **Digital Signature**: Type-in digital script signature block.

---

## 🚀 How to Run Locally

Since this is built with clean HTML5, Tailwind CSS, and Vanilla JavaScript, **no setup or installation is required**:

1. Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).
2. *Or* run a simple local web server with Python:
   ```bash
   python -m http.server 8000
   ```
   Then open `http://localhost:8000`.
